Gestão de alunos

Controle de Alunos Consultoria Online

Arraste os cards entre as colunas para atualizar a etapa de cada aluno. Em telas sem suporte a arrastar (celular/tablet), use o menu "Mover para" dentro do card.

Cada espaço (Victor / Gabi) guarda seus próprios dados, separadamente, neste navegador. Não há senha — é só uma forma de organizar sem misturar os alunos de cada um.

Adicionar aluno

Para um aluno novo, deixe "protocolo atual" como 1 e a mesma data de início. Se o aluno já estiver no meio do plano, ajuste os dois campos acima.

Confirmar troca de treino

Informe a data em que o novo treino realmente começou a valer. Isso ajusta a previsão de término do plano com base no atraso real.
