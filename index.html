Controle de Alunos

Alunos

Arraste os cards entre as colunas para atualizar a etapa. Em celular/tablet, onde arrastar não funciona bem, use o menu "Mover para" dentro do card.

Cada espaço (Treinador / Nutricionista) guarda seus próprios dados, separadamente, neste navegador. O espaço da Nutricionista pede usuário e senha; o do Treinador não. Atenção: esse login é apenas uma trava simples no navegador (sem servidor) — antes de publicar esta página para acesso externo, vale reforçar com um controle de acesso de verdade, já que envolve dados de pacientes.

Adicionar aluno

Para um aluno novo, deixe "protocolo atual" como 1 e a mesma data de início. Se o aluno já estiver no meio do plano, ajuste os dois campos.

Para um paciente novo, use a data da primeira consulta. O envio do PARQ (15 dias depois) e a previsão de retorno são calculados automaticamente a partir dessa data.

Confirmar troca de treino

Informe a data em que o novo treino realmente começou a valer. Isso ajusta a previsão de término do plano com base no atraso real.
