API da Anthropic (Claude)

Essa ferramenta roda 100% no seu navegador — não existe servidor por trás. Sua chave fica salva apenas no localStorage deste navegador e é enviada direto para a API da Anthropic a cada análise. Nunca compartilhe essa chave.

Se a chamada falhar com erro de modelo desconhecido, troque para outro identificador de modelo válido na sua conta.

Como funciona o pipeline

Entrada: você cola a transcrição/fala de um vídeo que já performou bem (Instagram, TikTok, YouTube etc.) — copiada manualmente por você.

Inteligência: Transcrição Estruturada → Autópsia Completa → DNA Estratégico → SEO Social.

Criação: a partir do DNA, você informa seu nicho/público/objetivo e a IA gera ideias originais + matriz de possibilidades.

Otimização: cada ideia pode receber um Score (0-100) ponderado pelo seu objetivo (viralização, vendas ou SEO), com sugestão de versão otimizada.

Tudo fica salvo no "Banco de Ideias" (também no seu navegador).
